Photovoltaic Defect Inspection System

01. System Problem & Context

Microcracks and finger interruptions in solar cells are invisible to the naked eye under visible light. Electroluminescence (EL) imaging reveals these subsurface defects, but manual optical inspection on high-throughput manufacturing lines introduces high latency, human fatigue, and inconsistent fault classification.

02. Engineering & Algorithm Architecture

  • Image Preprocessing Pipeline: Implemented OpenCV-based Contrast Limited Adaptive Histogram Equalization (CLAHE) and spatial normalization to mitigate uneven illumination artifacts across monocrystalline and polycrystalline EL samples.
  • Neural Network Design: Constructed and trained a 3-Block Convolutional Neural Network (CNN) architecture using TensorFlow/Keras optimized with dropout and L2 regularization to prevent overfitting on subtle microcrack feature sets.
  • Inference Optimization: Calibrated probability decision thresholds specifically prioritizing Recall over Precision to prevent false negatives in high-cost PV assembly lines.

Technical Stack

Python, TensorFlow / Keras, OpenCV, NumPy, Matplotlib, Pandas

Measured Key Results

70% Defect Recall | 94.9ms Single-Batch Inference Latency | AUC-ROC 0.78

Automated Stone-Cutting PLC & HMI System

01. Operational Requirements & Challenge

An industrial stone processing machine required full control modernization to transition from legacy manual relay switching to an automated, deterministic system. The main challenges included extreme mechanical vibration, high inertia disk blade startup torque, and severe blade overheating risks if cooling water flow stalled.

02. Control Engineering Solution

  • PLC & Modbus Architecture: Programmed a Kinco PLC using Ladder Diagram (LD) logic for dual-blade axial motion coordination, integrating hardware limit switches and rotary encoder feedback.
  • VFD Speed Regulation: Integrated Variable Frequency Drives (VFDs) controlling main saw blade induction motors, implementing smooth acceleration/deceleration ramps to mitigate mechanical shock and peak current draw.
  • Safety Interlocks & Cooling System: Engineered mandatory hardware/software safety interlocks requiring verified hydraulic cooling pump pressure before allowing disk engagement, preventing catastrophic tool failure.
  • Industrial HMI UI/UX: Designed human-machine interface screens displaying real-time operational parameters, emergency stop status, motor current consumption, and fault diagnostics.

Hardware & Protocols

Kinco PLC, Kinco HMI, VFD Motor Controllers, Modbus RTU (RS-485)

Field Commissioning Result

±0.5 cm Axis Positioning Accuracy | Zero Thermal Blade Damage | Fully Deployed

Sequential Chiller Pump Management

01. Facility Infrastructure Need

Simultaneous direct-on-line (DOL) startup of multiple high-power chiller circulating pumps caused severe voltage drops and inrush current spikes across the building's electrical distribution panel. Furthermore, uneven pump usage led to premature mechanical seal wear on primary units.

02. Discrete Logic Implementation

  • Siemens LOGO! Logic Controller: Programmed Functional Block Diagrams (FBD) managing a 3-stage staggered startup sequence with configurable delay timers ($t_{delay} = 15s$) to flatten inrush current transients.
  • Equally Distributed Duty Cycle: Implemented automatic lead-lag rotation logic shifting primary operational duty across all 3 pumps on a schedule, balancing cumulative operating hours.
  • Fault Monitoring & Auto-Failover: Configured thermal overload relay discrete inputs. If a running pump trips, the logic instantly engages the standby unit and triggers an audible visual alarm on the panel.

Hardware & Software

Siemens LOGO! 8 Micro-PLC, LOGO! Soft Comfort (FBD), Thermal Relays

Operational Impact

Eliminated Grid Current Spikes | Automatic Backup Shift | Zero Down-time
